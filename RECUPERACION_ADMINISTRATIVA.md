# Comprobación previa y conservación de originales

La recuperación efectiva todavía no está implementada. `python -m app.recuperacion_administrativa --operacion OPERACION --confirmar-operacion OPERACION` realiza una comprobación de solo lectura bajo el bloqueo exclusivo y termina con estado bloqueado. La confirmación identifica la operación; no habilita una recuperación.

La continuidad de un original inventariado puede comprobarse mediante `python -m app.desplazamiento_original inspeccionar --operacion OPERACION --confirmar-operacion OPERACION --componente base` (o `storage` o `clave`). La acción explícita `desplazar` cambia la ubicación del original a `.siged-conservacion-OPERACION`; no instala ningún componente, no modifica el registro v2 ni permite arrancar SIGED. Se exige la preparación comprobada y el bloqueo exclusivo. Si un componente estaba ausente se conserva esa ausencia.

Antes de cualquier movimiento se publica un plan vinculado al registro y al inventario v2; antes de cada movimiento se publica su intención. Los registros de archivo se vacían y publican sin sobrescribir; Windows no garantiza aquí la durabilidad del enlace de directorio ante un apagón. Si faltan o se contradicen las evidencias, se conserva el directorio y se exige revisión. Después de una interrupción, el comando inspecciona origen y destino, compara identidad y huellas del árbol completo y solo confirma un movimiento ya realizado si la evidencia es inequívoca. No utiliza rutas arbitrarias procedentes del registro. Los hashes indican integridad, no autenticidad.

El directorio de conservación tiene ACL restringida. Los originales desplazados conservan sus ACL existentes; no se modifican para simular permisos nuevos. La compatibilidad con la cuenta de servicio definitiva debe verificarse durante el despliegue. Los procesos que no participan en el bloqueo requieren controles administrativos adicionales.

El selector y el inspector generales de la preparación aún solo reconocen las ubicaciones previas; la continuidad de originales desplazados se comprueba mediante el módulo específico. La futura recuperación deberá integrar esa comprobación, preservar el estado activo previo, registrar sus propios pasos y validar las ACL de servicio. Ninguna comprobación ni constancia actual autoriza restaurar o habilitar el arranque. La clave histórica de entorno tampoco se acredita por el valor de la variable actual.
